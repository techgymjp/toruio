## 日本語

**アプリ名**（30 文字以内）

```
目指せ盗塁王 - 代走で300盗塁に挑め
```

**簡単な説明**（80 文字以内）

```
代走のあなたが一塁から二盗・三盗・ホームスチールを狙う！リードと牽制の駆け引き、決死のヘッドスライディング。3D盗塁ゲーム
```

**詳しい説明**

```
9回、一点を争う場面。代走として一塁に立ったあなたの仕事はただひとつ――盗むこと。
二盗、三盗、そしてホームスチールまで。100回のチャレンジで、何個の盗塁を決められるか？

■ リードと牽制の駆け引き
・リードボタンを押している間カニ歩きでリード、離すと帰塁
・リードが大きいほどスタートは有利。でも牽制球が来やすくなる
・「牽制!」が出たら指を離して帰塁。間に合わなければ頭から飛び込め
・投げるふりの偽投から、すぐに投球してくる投手も

■ スタートは自動、あとは足と勇気
・投手が投げた瞬間に自動でスタート。ダッシュボタンで全力疾走
・塁の手前でスライディング。押しどきはボタンが光って「今!」と教えてくれる
・ヘッドスライディングは一番速いが、早すぎれば届かず、遅すぎればオーバースライド
・足からのスライディングは少し遅いが確実。滑らずに走り切ればスタミナを温存できる
・きわどい判定はスローモーション。塁審の「セーフ!」「アウト!」に息をのむ

■ スタミナの配分が勝負を決める
・リードやスライディングのたびにスタミナが減り、足が遅くなる
・二盗・三盗で飛ばしすぎると、ホームスチールのころには足が残っていない
・相手の投手はクイックの速さ・牽制の多さ、捕手は肩の強さがチャレンジごとに変わる

■ ナイターの球場と大歓声
・ランナーの背中越しに次の塁を見る3D視点。満員のスタンドと照明塔
・トランペットと太鼓の応援、走り出すと「おおっ」とどよめく
・盗塁を決めるたびに花火と大歓声。ホームスチールなら特大の花火

■ その他
・「草野球の代走」から「伝説の走り屋」までの称号
・二盗・三盗・ホームスチールそれぞれの成功率を結果画面に表示
・結果を友だちにシェア
・オフラインでも遊べる（広告とシェアには通信が必要）
・日本語と英語に対応

さあ、プレイボール。目指せ、盗塁王！
```
