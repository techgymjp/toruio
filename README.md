# 目指せ盗塁王 (Steal King)

代走のあなたが一塁から **二盗 → 三盗 → ホームスチール** を狙う、盗塁のブラウザゲームです。
**100 チャレンジ** で何個盗めるか(理論上の最大は 300 盗塁)。アウトになったら一塁からやり直しです。

画面は **ランナーの背中越しに次の塁を見る3D視点**。ナイター照明のスタジアム・満員のスタンド・花火・応援などの
質感と演出は、センターフライ(techgymjp/center-fly)・ホームラン競走(techgymjp/homerun)と揃えています。

`index.html` をブラウザで開くだけで遊べます(Web 版はビルド不要)。Android アプリ版もあります(下記)。
3D描画に同梱の three.js(`vendor/three.min.js`, MIT License)を使っています。
Vercel では `vercel.json` の指定で `npm run build` が `www/` を作り、それを公開します。

## 操作

| 操作 | タッチ / マウス | キーボード |
| --- | --- | --- |
| リード | 左下の **リード** ボタン長押し(離すと帰塁) | Space / Z(押している間) |
| ダッシュ | **ダッシュ** ボタン長押し | Shift / X(押している間) |
| スライディング(足から) | **スライディング** ボタン | C / ↓ |
| ヘッドスライディング | **ヘッドスライディング** ボタン(牽制のときは頭から帰塁) | V / ↑ |
| 一時停止 | — | P / Esc |
| 音のオン/オフ | 画面上部のスピーカーボタン | M |

## 遊び方

1. **リード** — ボタンを押している間カニ歩きでリードを広げ、離すと塁に戻ります。
   リードが大きいほどスタートは有利ですが、**牽制球** が来やすくなります(下のメーターの色が危険度)。
2. **牽制** — 投手が塁のほうへ振り向くと「牽制!」。指を離して帰塁し、間に合わなければアウト。
   **ヘッドスライディング** ボタンで頭から飛び込んで戻れます(少し走って勢いがついてから飛ぶと遠くまで届く)。
   - **偽投(牽制のふり)**: 振り向くところまでは本物の牽制と同じで見分けられません(プレートを外してからの偽投という扱い)。
     投げるふりの後に「フェイク!」と出てホームに向き直り、そのまますぐ投球してくることが多いので、
     戻りかけていたり頭から飛び込んで倒れていたりするとスタートが遅れます。偽投の多い投手は左上に「偽投あり」と出ます。
3. **スタート** — 基本は 1 球目に走ります。投手が投球モーションに入ると **自動でスタート**。
   **ダッシュ** を押している間は全力疾走、押さないと流して走るぶん遅くなります。
4. **スライディング** — 塁の手前で滑り込みます。滑らずに走り切ると、塁の直前で一気に止まって立ったまま着きます(少し遅いがスタミナを使わない)。
   **押しどきになるとボタンが点滅して「今!」と出ます**(見てから指が動くまでの約 0.2 秒ぶん早めに点滅するので、点滅を見たらすぐ押す)。
   下のメーターにも、今の速さで滑ったときに届く範囲が出ます(赤い丸 = 自分、右端 = 塁、オレンジ = ヘッド、緑 = 足から)。
   - **ヘッドスライディング**: 地面を蹴って低く飛び込み(加速)、着地して滑る。いちばん速いが、早すぎると届かず、
     遅すぎると手がベースに着いたときに勢いがありすぎて止まれず **オーバースライド** でアウト。スタミナを多く使う
   - **スライディング(足から)**: 少し加速して滑り込む。ヘッドより少し遅いが、足がベースに引っかかって止まるのでオーバースライドしない
5. 送球より先に塁に触れていればセーフ。成功すると次の塁へ、三塁からは **ホームスチール**(投手はワインドアップ)。
   本塁は踏めば得点なので、**駆け抜けてよく、ヘッドスライディングでオーバースライドしてもセーフ** です(捕手のタッチより先に踏んだ時点でセーフ)。

### 走り切る・スライディング・ヘッドスライディングの使い分け

| | 速さ | 失敗のしやすさ | スタミナ |
| --- | --- | --- | --- |
| 走り切る | いちばん遅い(リード 5m で成功率 4 割くらい) | 失敗なし | 使わない |
| スライディング(足から) | 中くらい | 早すぎると届かないだけ。オーバースライドなし | 14 |
| ヘッドスライディング | いちばん速い | 押せる幅が狭く、遅いとオーバースライド | 34 |

スタミナは 1 チャレンジの間ずっと減ったままなので、二盗・三盗は走り切ってスタミナを残し、
いちばん厳しいホームスチールでヘッドスライディング、という配分も作戦になります。
(毎回ヘッドスライディングだとホームスチールのころには足が残っておらず、本盗はほとんど決まりません。
二盗・三盗を走り切り・足からで温存すると、盗塁の合計はほぼ同じで本盗が 2〜3 倍に増えます)

### スタミナ

1 チャレンジの間、**リードをするたび(2)・スライディングするたび(足から 14・ヘッド 34・頭から帰塁 10)** にスタミナが減り、足が遅くなります(スタミナ 0 で最高速の 6 割。次のチャレンジで回復)。
むやみにリードを出し入れしたり、牽制のたびに飛び込んだりすると、ホームスチールのころには足が残っていません。

### 投手と捕手

チャレンジごとに相手のバッテリーが変わります(左上に表示)。

- 投手: クイックの速さ(モーションが大きい投手は走りやすい)、牽制の多さ、偽投の多さ
- 捕手: 肩の強さ
- たまにワンバウンドの投球や悪送球も

### 演出

- タイトル画面の「遊び方」ボタンで操作説明の画面を開く(キーボードは H)
- スマホでは文字とボタンを大きく表示。カメラは離れたところから望遠で写すので投手や塁が大きく見える
- スライディングで土けむりが上がる。判定がきわどくなるとスローモーション、塁審の「セーフ」「アウト」のジェスチャー
- 盗塁成功で花火と大歓声(ホームスチールは特大)。10 連続盗塁ごとにエアホーン
- 音はすべて Web Audio API で合成(球場のざわめき、トランペット応援、どよめき、スライディング・送球・ミットの音)
- 日本語・英語に対応(端末の言語で自動選択、タイトル画面で切り替え)
- 結果画面・シェア文・成績画像に二盗・三盗・ホームスチールそれぞれの成功率を表示(牽制死もその塁の失敗に数える)
- ベスト記録はブラウザに保存。結果画面からシェア(対応スマホは成績画像つき。X・LINE・コピー)。
  シェアには紹介記事 https://techgym.jp/column/claude-code-game-toruio/ が付きます

## ファイル構成

- `index.html` / `style.css` — 画面(2 枚のキャンバス: 3D と操作・表示のオーバーレイ)
- `game.js` — ゲームの進行・ランナー・投手・野手・判定・操作・表示
- `scene3d.js` — 3D 描画(球場・観客席・照明・花火はセンターフライと同じ作り)
- `sound.js` — 効果音と応援(Web Audio API)
- `i18n.js` — 日本語・英語の文言
- `ads.js` — Google AdMob 広告(Android アプリのときだけ動く)。`ads-config.js` / `build-info.js` は Web 版用の既定値で、アプリのビルド時に生成し直す
- `scripts/build-web.js` — アプリに同梱するファイルを `www/` にコピーする
- `android/` — Android アプリ(Capacitor)。`assets/` はアイコンと起動画面の元画像

テスト用に `window.Toruio` からゲームの状態や自動操作(`setBot`)を使えます。

## Android アプリ

[Capacitor](https://capacitorjs.com/) でゲームのファイルをアプリに同梱し、Android アプリにしています(オフラインで遊べます)。
構成は techgymjp/jet-fighter の `docs/ANDROID_PORTING.md`(techgymjp/center-fly と同じ)です。

- パッケージ名: `jp.techgym.toruio`
- アプリ名: 端末の言語が日本語なら「盗塁王」、それ以外は「Steal King」
- 横画面固定・全画面・プレイ中は画面を消さない
- 戻るボタン: プレイ中は一時停止(一時停止中は再開)、遊び方の画面ではトップへ、トップ・結果画面ではアプリを終了
- 別アプリに切り替えると自動で一時停止して音を止める
- シェアは Android の共有メニュー
- 広告(AdMob)
  - バナー: トップ・遊び方・一時停止・結果画面の下中央だけ(プレイ中は操作ボタンと重なるので出さない)
  - インタースティシャル: 「プレイボール」(トップ・遊び方から)、トップに戻る(遊び方・一時停止・結果画面から)、一時停止からの再開、結果画面の「もう一度」のたびに毎回
  - リワード: 盗塁でアウトになったときに「広告を見てこの盗塁をやり直す」(1 ゲーム 5 回まで。6 秒で自動的に次へ)。
    見終わると、その挑戦の成績を取り消し、同じ塁・同じスタミナ・同じ投手の動き(同じ乱数)でもう一度。使った回数は結果画面とシェア文に「やり直し N 回」と出る
  - 本番の広告ユニット ID は `ads.js` の `UNITS.production`、アプリ ID は `android/app/src/main/res/values/strings.xml` の `admob_app_id`。
    ID が空の広告の種類は本番ビルドでは出さない(アプリ ID は届くまで Google 公式のテスト用 ID)
  - EU など同意が必要な地域ではトップ画面に「広告の設定」
- トップ画面にバージョン(ビルド番号)とプライバシーポリシーへのリンク

ビルドは GitHub Actions(`.github/workflows/android.yml`)で行います。

1. `npm ci` → `npm run build`(`www/` に Web ファイルをコピーし、`ads-config.js` と `build-info.js` を生成)→ `npx cap sync android` → `./gradlew assembleDebug`
2. 既定ブランチなら、Release `android-latest` の `toruio.apk` を差し替え(動作確認用・テスト広告)
   - リリース画面: `https://github.com/techgymjp/toruio/releases/tag/android-latest`(QR コード: `docs/apk-qr.png`)
   - APK 直接: `https://github.com/techgymjp/toruio/releases/latest/download/toruio.apk`
3. GitHub Secrets に署名鍵(`ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD` / `ANDROID_KEY_ALIAS` / `ANDROID_KEY_PASSWORD`)があれば、本番広告で署名付き AAB を作り Artifact(`toruio-release-aab`)に上げる

手元で試すとき: `npm install` → `npm run android:sync` → `npm run android:open`(Android Studio が必要)。
アイコンと起動画面は `assets/` の元画像から `npx @capacitor/assets generate --android` で生成しています。
