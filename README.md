# 目指せ盗塁王 (Steal King)

代走のあなたが一塁から **二盗 → 三盗 → ホームスチール** を狙う、盗塁のブラウザゲームです。
**100 チャレンジ** で何個盗めるか(理論上の最大は 300 盗塁)。アウトになったら一塁からやり直しです。

画面は **ランナーの背中越しに次の塁を見る3D視点**。ナイター照明のスタジアム・満員のスタンド・花火・応援などの
質感と演出は、センターフライ(techgymjp/center-fly)・ホームラン競走(techgymjp/homerun)と揃えています。

`index.html` をブラウザで開くだけで遊べます(ビルド不要)。3D描画に同梱の three.js(`vendor/three.min.js`, MIT License)を使っています。
GitHub Pages などの静的ホスティングにそのまま置けます。

## 操作

| 操作 | タッチ / マウス | キーボード |
| --- | --- | --- |
| リード | 左下の **リード** ボタン長押し(離すと帰塁) | Space / Z(押している間) |
| ダッシュ | **ダッシュ** ボタン長押し | Shift / X(押している間) |
| スライディング(足から) | **スライディング** ボタン | C / ↓ |
| ヘッドスライディング | **ヘッドスライディング** ボタン(牽制のときは頭から帰塁) | V / ↑ |
| 一時停止 | — | P / Esc |
| 音のオン/オフ | 画面上部のスピーカーボタン | M |

## 遊び方

1. **リード** — ボタンを押している間カニ歩きでリードを広げ、離すと塁に戻ります。
   リードが大きいほどスタートは有利ですが、**牽制球** が来やすくなります(下のメーターの色が危険度)。
2. **牽制** — 投手が塁のほうへ振り向くと「牽制!」。指を離して帰塁し、間に合わなければアウト。
   **ヘッドスライディング** ボタンで頭から飛び込んで戻れます(少し走って勢いがついてから飛ぶと遠くまで届く)。
3. **スタート** — 基本は 1 球目に走ります。投手が投球モーションに入ると **自動でスタート**。
   **ダッシュ** を押している間は全力疾走、押さないと流して走るぶん遅くなります。
4. **スライディング** — 塁の手前で滑り込みます。滑らないと手前で減速して立ったまま止まるので遅くなります。
   下のメーターに、今の速さで滑ったときに届く範囲が出ます(オレンジ = ヘッド、緑 = 足から)。
   - **ヘッドスライディング**: 地面を蹴って低く飛び込み(加速)、着地して滑る。いちばん速いが、早すぎると届かず、
     遅すぎると手がベースに着いたときに勢いがありすぎて止まれず **オーバースライド** でアウト。スタミナを多く使う
   - **スライディング(足から)**: 少し加速して滑り込む。ヘッドより少し遅いが、足がベースに引っかかって止まるのでオーバースライドしない
5. 送球より先に塁に触れていればセーフ。成功すると次の塁へ、三塁からは **ホームスチール**(投手はワインドアップ)。

### スタミナ

1 チャレンジの間、**リードをするたび・スライディングするたび** にスタミナが減り、足が遅くなります(次のチャレンジで回復)。
むやみにリードを出し入れしたり、牽制のたびに飛び込んだりすると、ホームスチールのころには足が残っていません。

### 投手と捕手

チャレンジごとに相手のバッテリーが変わります(左上に表示)。

- 投手: クイックの速さ(モーションが大きい投手は走りやすい)、牽制の多さ
- 捕手: 肩の強さ
- たまにワンバウンドの投球や悪送球も

### 演出

- タイトル画面の「遊び方」ボタンで操作説明の画面を開く(キーボードは H)
- スマホでは文字とボタンを大きく表示。カメラは離れたところから望遠で写すので投手や塁が大きく見える
- スライディングで土けむりが上がる。判定がきわどくなるとスローモーション、塁審の「セーフ」「アウト」のジェスチャー
- 盗塁成功で花火と大歓声(ホームスチールは特大)。10 連続盗塁ごとにエアホーン
- 音はすべて Web Audio API で合成(球場のざわめき、トランペット応援、どよめき、スライディング・送球・ミットの音)
- 日本語・英語に対応(端末の言語で自動選択、タイトル画面で切り替え)
- ベスト記録はブラウザに保存。結果画面からシェア(対応スマホは成績画像つき。X・LINE・コピー)

## ファイル構成

- `index.html` / `style.css` — 画面(2 枚のキャンバス: 3D と操作・表示のオーバーレイ)
- `game.js` — ゲームの進行・ランナー・投手・野手・判定・操作・表示
- `scene3d.js` — 3D 描画(球場・観客席・照明・花火はセンターフライと同じ作り)
- `sound.js` — 効果音と応援(Web Audio API)
- `i18n.js` — 日本語・英語の文言

テスト用に `window.Toruio` からゲームの状態や自動操作(`setBot`)を使えます。
